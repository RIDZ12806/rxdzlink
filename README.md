# RXDZ Hub

أنشئ موقعًا شخصيًا احترافيًا جدًا باسم RXDZ لمطور Roblox وصانع محتوى.

أريد تصميمًا داكنًا وفخمًا بطابع تقني مستقبلي، مع ألوان أساسية أسود وأزرق داكن وأزرق مضيء، وإضاءات Neon وGlow وتفاصيل بصرية احترافية.

سأرفق مع الطلب صورًا لكل منصة من منصات التواصل الاجتماعي، بالإضافة إلى صورة اللعبة الرئيسية الخاصة بي في Roblox.

مهم جدًا: استخدم الصور المرفقة كما هي، وضع كل صورة/أيقونة في المكان المخصص للمنصة الصحيحة، ولا تستبدلها بأيقونات عشوائية.

التأثيرات والتفاعل

أريد الموقع مليئًا بالتفاصيل التفاعلية دون أن يصبح مزعجًا:

- تحريك احترافي للأسماء والعناوين.
- ظهور العناصر بحركات عند التمرير.
- Hover Effects على الأزرار والأيقونات.
- تأثير Glow عند تحريك المؤشر.
- تأثير Ripple أو Click عند الضغط.
- حركات خفيفة للأيقونات.
- خلفية متحركة تحتوي على جزيئات وإضاءات وتأثيرات تقنية.
- انتقالات Smooth بين الأقسام.
- تأثيرات خاصة لزر دخول اللعبة.
- اجعل كل العناصر تبدو حية وتفاعلية.

التصميم

اجعل الموقع Responsive بالكامل للهاتف والكمبيوتر، سريعًا ومنظمًا، مع خطوط واضحة وتباعد احترافي.

أريد النتيجة النهائية أن تبدو كموقع شخصي حقيقي ومتطور لمطور Roblox، وليس صفحة روابط عادية. اهتم بالتفاصيل الصغيرة، الإضاءة، الحركات، التدرجات، الحواف والتفاعل.
